## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "Roblox.rbxlx"
```

Next, open `Roblox.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
## Imperium — Consul (panneau admin)

Ouvrir : **F2** ou le bouton « Imperium » en bas à droite (staff uniquement). À gauche les 12 familles et l'Aide, en haut leurs systèmes. Seul ce que le rang autorise est affiché.

Qui est staff : [src/server/Config/Senatus.luau](src/server/Config/Senatus.luau)
- `membres` : `[UserId] = "moderateur" | "admin" | "fondateur"`
- `groupe` : rangs attribués selon le rang dans un groupe Roblox
- le créateur du jeu est fondateur ; en Studio, ton compte (Play) ou Player1 (Test > Local Server)

Pour tester les sanctions en Studio : Test > Clients and Servers > 2 joueurs. Player1 est fondateur, Player2 est la cible.
Pour que les sanctions survivent à la session : Game Settings > Security > *Enable Studio Access to API Services*.

| Système | Rôle ici |
|---|---|
| Conditor | démarre les systèmes dans l'ordre des dépendances |
| Senatus | rangs et permissions |
| Consul | requêtes du panneau, vérification des droits, journalisation |
| Praetor | avertir, mute, expulser, bannir (persistant, inter-serveurs) |
| Censor | fiche des joueurs et journal du staff |
| Praefectus | verrouillage, redémarrage avec compte à rebours |
| Praeco | bannières d'annonce |
| Lex | réglages modifiables à chaud |
| Tabularius | sauvegarde (DataStore, repli en mémoire) |
| Veredarius | remotes nommés avec limitation de débit |
